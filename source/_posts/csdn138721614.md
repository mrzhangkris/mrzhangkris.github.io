有些数据只配活在内存里：编译的临时产物、压测时反复读写的高速缓存、不想磨损 SSD 的碎文件。这类需求不用装第三方工具，Linux 内核自带的 brd 模块一条 modprobe 就能凭空造出一块"磁盘"，读写速度就是内存带宽。

> 诚实边界：brd 是内核模块，容器环境无法加载宿主内核，本文流程未实跑，命令来自原文并对照内核文档（Documentation/admin-guide/blockdev/ramdisk.rst）；CentOS 7/8/9、Rocky Linux 通用。

## 核心机制一句话

brd（block device in RAM）在内核里把一块内存区域包装成标准块设备：你拿到的是真正的 `/dev/ramN` 设备节点，可以分区、可以 mkfs 任意文件系统——这是它与 tmpfs 最大的不同。

## 创建内存盘

加载 brd 模块，参数直接跟在后面：

```bash
modprobe brd rd_nr=1 rd_size=16777216 max_part=0
```

三个参数：`rd_nr` 是要几块盘，这里 1 块；`rd_size` 是单块盘大小，单位 KB，16777216 KB 正好 16GB；`max_part=0` 表示不启用分区支持，整块盘直接用。

加载成功后，`/dev` 下就多出了 ram0 这块盘，可以确认一下：

```bash
lsblk /dev/ram0
```

验证点：`lsblk` 能看到 ram0 且 SIZE 列与 rd_size 一致，模块才算加载成功。

## 格式化并挂载

内存盘也要走普通磁盘的流程。先格式化成 ext4：

```bash
mkfs.ext4 /dev/ram0
```

然后挂到目录上（挂载点目录要事先存在）：

```bash
mkdir -p /data
mount /dev/ram0 /data
```

此后所有写入 /data 的数据都落在内存里，断电即失——这正是用它的目的，也是它的代价。

## 用完卸载

不用了就按顺序收掉：卸载文件系统，再把内核模块移除：

```bash
umount /data
modprobe -r brd
```

`modprobe -r` 会把 brd 从内核里卸掉，盘上数据随之清空。跳过 umount 直接 `-r` 时模块会因占用而卸不掉，这个顺序不能反。

## 开机自动创建并挂载

modprobe 的效果重启就没了。想每次开机都有这块盘，要把参数固化到 modprobe 配置里，再让 rc.local 负责格式化和挂载：

```bash
echo "options brd rd_nr=1 rd_size=16777216 max_part=0" >> /etc/modprobe.d/memdisk.conf
echo "mkfs.ext4 /dev/ram0" >> /etc/rc.d/rc.local
echo "mount /dev/ram0 /data" >> /etc/rc.d/rc.local
```

第一行让内核开机自动加载 brd 并带上参数；后两行追加进 rc.local 的命令每次开机都会执行——内存盘每次起来都是空的，mkfs 和 mount 都得重来。

## brd 还是 tmpfs：选错了白忙

同样是内存存储，两者语义不同。tmpfs 是文件系统，`mount -t tmpfs -o size=4G tmpfs /mnt` 直接可用，访问路径就是目录，大多数场景它最省事。brd 的价值在于块设备语义：应用坚持要一个 `/dev/` 设备（某些数据库、测试工具、需要 mkfs 特定文件系统如 xfs 的场景），tmpfs 给不了，brd 补位。反过来，只是想给编译提提速，用 tmpfs 就够了，绕道 brd 属于多余动作。

## 注意事项

- 内存盘没有任何持久性，只放可再生的临时数据，重要文件别往里放。
- 盘吃的是真实物理内存：rd_size 给多大，写满就要占多大，按实际需要定，别拍脑袋开大。
- 挂载点目录要先建好，mount 不会替你 mkdir。
- rc.local 方案在部分新版发行版上默认没有启用，动手前先确认这台机器的 rc.local 机制仍然生效（`chmod +x /etc/rc.d/rc.local` 且 systemd 的 rc-local 服务处于 active）。
- brd 需要内核加载模块支持；个别精简内核（部分云镜像、容器宿主）不带 brd，`modprobe brd` 报 Module not found 时先确认 `ls /lib/modules/$(uname -r)/` 下有无 brd.ko。

## 小结

回到开头的场景：编译产物、压测缓存这些"用完即弃"的数据，brd 一条 modprobe 就能给一块内存带宽的块设备。记住三件事——数据不持久、容量就是内存、rc.local 要重启流程——它就是一台随取随用的临时高速盘。
