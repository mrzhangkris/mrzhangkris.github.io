公网机器上怀疑有人在爆破 SSH，或者单纯想看看最近都有谁在尝试登录失败，`lastb` 一条命令就能列出来。它显示的是错误登录列表，从 `/var/log/btmp` 里读数据——这个文件专门记录登录失败的事件。

## 基本用法

直接执行 `lastb`，输出每行一次失败登录：用户名、来源（终端和 IP）、时间：

```bash
[root@localhost ~]# lastb
root     ssh:notty    192.168.0.201    Mon Feb 13 11:38 - 11:38  (00:00)
erdaf    ssh:notty    192.168.0.201    Mon Feb 13 11:06 - 11:06  (00:00)
erdaf    ssh:notty    192.168.0.201    Mon Feb 13 11:06 - 11:06  (00:00)
```

## 常用选项

只看最近几条，`-n` 指定条数，简写是直接跟数字：

```bash
[root@localhost ~]# lastb -n 1
root     ssh:notty    192.168.0.201    Mon Feb 13 11:38 - 11:38  (00:00)

[root@localhost ~]# lastb -1
root     ssh:notty    192.168.0.201    Mon Feb 13 11:38 - 11:38  (00:00)
```

`-d` 把 IP 地址反解成主机名：

```bash
[root@localhost ~]# lastb -d
root     ssh:notty    bogon            Mon Feb 13 11:38 - 11:38  (00:00)
erdaf    ssh:notty    bogon            Mon Feb 13 11:06 - 11:06  (00:00)
erdaf    ssh:notty    bogon            Mon Feb 13 11:06 - 11:06  (00:00)
```

## 相关的登录日志文件

btmp 只记录失败的登录，登录相关的日志其实是一组文件，各有分工：

- **btmp**：只记录登录失败。
- **utmp**：记录当前的用户登录信息，包括登录终端、登出状态、系统启动时间等（`uptime` 读的就是它）。
- **wtmp**：utmp 的历史归档，包含当前和历史登录信息，`last` 命令读它。

另外两个相关命令：

- `lastlog`：显示系统中所有用户最近一次的登录信息。
- `last`：列出目前与过去登入系统的用户相关信息。

## 注意事项

- btmp 文件可能很大，爆破严重的机器上先 `-n` 限定条数，别直接全量输出。
- `lastb` 需要 root 权限读取 btmp 文件。
- 失败记录多不代表一定被入侵，但持续的陌生 IP 高频失败值得配上 fail2ban 之类的封禁措施。
