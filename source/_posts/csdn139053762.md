磁盘快满、又不想停机，就是云磁盘热扩容的用武之地：控制台把盘调大，系统里再把分区和文件系统跟着拉长，全程服务不中断。这篇以 50GB 扩到 100GB 为例，走一遍完整流程。

## 什么是热扩容

热扩容指在不关闭系统、不终止服务的情况下动态增加存储容量。云环境里尤为常用——服务要保高可用，不能为了加块盘停一次机。

## 使用场景

- **数据快速增长的平台**：电商网站、社交平台这类存储消耗快的服务。
- **数据库扩展**：不允许停机扩存储的数据库系统。
- **大数据处理**：需要动态扩容装下大数据集的分析平台。
- **虚拟机和容器环境**：在线扩盘以支持更多应用和服务。

## 前提条件

执行系统和磁盘管理操作需要 root 或 sudo 权限，同时确认磁盘上的文件系统支持在线扩展。

## 步骤 1：在云平台上增加磁盘容量

1. 登录云平台管理控制台；
2. 进入"存储"或"磁盘"管理页面；
3. 选中要扩容的磁盘并修改容量，例如从 50GB 加到 100GB；
4. 提交操作，等平台完成扩容。

## 步骤 2：确认新的磁盘空间

回到 Linux 系统里用 lsblk 确认：

```bash
lsblk
```

![配图](/images/csdn/figures/csdn139053762.png)

```text
NAME    MAJ:MIN RM   SIZE RO TYPE MOUNTPOINT
sda       8:0    0   100G  0 disk
├─sda1    8:1    0     2G  0 part /boot
└─sda2    8:2    0    98G  0 part /
```

sda 显示为 100G，说明平台侧扩容已经到位。

## 步骤 3：扩展分区

用 growpart 把分区拉到整盘可用空间：

```bash
sudo growpart /dev/sda 2
```

再执行一次 `lsblk`，确认分区大小已经更新。

## 步骤 4：扩展文件系统

分区变大不等于文件系统变大，最后一步按文件系统类型选命令。

ext4 文件系统：

```bash
sudo resize2fs /dev/sda2
```

xfs 文件系统：

```bash
sudo xfs_growfs /
```

用 df -h 确认结果：

```bash
df -h
```

```text
Filesystem      Size  Used Avail Use% Mounted on
/dev/sda2        98G   20G   78G  21% /
```

Avail 一列涨上去，扩容就完成了。

## 注意事项

- 动磁盘前先备份重要数据——热扩容一般不影响数据，但保险起见。
- 确认文件系统（如 ext4、xfs）支持在线扩展，某些情况下可能仍需离线操作。
- 各云平台对磁盘扩容的限制和入口不一样，先查自家平台的文档。
- 注意每次扩容的最小值和最大值限制。
- growpart、resize2fs 等工具的版本要能支持你的操作系统和文件系统。
