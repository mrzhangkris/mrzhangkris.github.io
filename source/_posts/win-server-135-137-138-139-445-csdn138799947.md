135、137、138、139、445 是 Windows 服务器上最常被扫的几个端口：135 对应 RPC，137/138 是 NetBIOS 的名称服务和数据报服务，139、445 都和文件共享（SMB）有关，历史上几次大规模勒索事件就是从 445 进来的。服务器上如果没有业务依赖这些端口，可以直接用系统自带的防火墙把它们全部封掉。

## 通过防火墙封禁端口

整个流程是在防火墙里新建一条入站规则，步骤如下：

1. 打开控制面板，选择「检查防火墙状态」，确认防火墙处于开启状态。
2. 进入防火墙的「高级设置」。
3. 左侧选择「入站规则」，再选择「新建规则」。
4. 规则类型选「端口」，下一步。
5. 选择规则要应用的协议（TCP 或 UDP），并指定要封禁的端口号，下一步。
6. 操作选「阻止连接」，下一步。
7. 应用配置文件保持默认（域、专用、公用全选），下一步。
8. 给规则起一个便于管理的名字，完成。

到这里规则就生效了，指向这些端口的入站连接都会被防火墙拦截。

## 注意事项

- 这套方案的前提是防火墙处于开启状态，防火墙关闭时规则不会生效。
- 封禁前先确认没有业务依赖：内网文件共享、打印机共享、域环境的部分服务会用到这几个端口，全封之前要评估影响。
- 封端口只是缓解手段，445 端口相关的 SMB 漏洞补丁还是要照常及时打。
