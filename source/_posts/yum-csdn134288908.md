:::info
本文基于Centos7.6系统搭建局域网YUM源，createrepo制作源仓库、OpenResty发布源
:::

[OpenResty官方源](https://openresty.org/cn/download.html%5D%28https://openresty.org/cn/download.html%5D%28https://openresty.org/cn/download.html%29)

### 二、规划

#### 2.1、部署步骤

1. 上传rpm包到仓库目录
2. 使用createrepo命令创建仓库
3. 配置OpenResty发布YUM源

#### 2.2、软件信息

| 软件 | 用途 | 下载地址 |
| --- | --- | --- |
| createrepo | 制作仓库 |  |
| OpenResty | 发布源信息 | [openresty-1.21.4.1.tar.gz](https://openresty.org/download/openresty-1.21.4.1.tar.gz) |

### 三、部署

#### 3.1、上传RPM包到本地

RPM包获取方式

1. ISO镜像
2. [同步镜像到本地](https://blog.csdn.net/u010260632/article/details/105444446)

#### 3.2、安装createrepo包

```bash
rpm -ivh deltarrpm-3.6-3.el7.x86_64.rpm
rpm -ivh libxml2-python-2.9.1-6.el7_2.3.x86_64.rpm
rpm -ivh python-deltarpm-3.6-3.el7.x86_64.rpm
rpm -ivh createrepo-0.9.9-28.el7.noarch.rpm
```

#### 3.3、创建仓库

```bash
createrepo -u -d /data/yum-repo/
```

-   /data/yum-repo/：仓库目录

#### 3.4、OpenResty配置

```nginx
location /{
  root   /data/yum-repo/;
}
```

-   /data/yum-repo/：仓库目录

### 四、附件

#### 4.1、更新自建仓库

```bash
createrepo --update /data/yum-repo/
```

-   /data/yum-repo/：仓库目录

#### 4.2、制作缓存

```bash
yum clean all
yum makecache
```

#### 4.3、自定义repo文件

```latex
[CentOS-7]
name=CentOS-$releasever
baseurl= http://IP:PORT
gpgcheck=0
enabled=1
```

-   IP:PORT为YUM服务器的ip地址和repo对外提供的端口

#### 4.4、下载失败错误

Error downloading packages
error was \[Errno 2\] Local file does not exist
![image.png](/images/csdn/134288908-1.png)
解决:
进入repo仓库目录，删除repodata/，更新自建仓库，并清除缓存
