需要自己掌控邮件收发——比如给内部系统发告警、给注册用户发通知——可以在 CentOS 7 上用 Postfix 做发送（MTA），Dovecot 做接收（IMAP/POP3），两者配合就是一套够用的自建邮件服务。这篇文章记录完整的安装、配置和测试过程。

## 一、安装必要的软件

安装 Postfix、Dovecot，以及用于安全通信的 cyrus-sasl-plain：

```bash
sudo yum install postfix dovecot cyrus-sasl-plain
```

## 二、配置 Postfix

编辑主配置文件：

```bash
sudo vi /etc/postfix/main.cf
```

![配图](/images/csdn/figures/centos-7-csdn138908418.png)

添加或修改以下行，搭起基本的邮件服务：

```conf
myhostname = mail.example.com
mydomain = example.com
myorigin = $mydomain
inet_interfaces = all
mydestination = $myhostname, localhost.$mydomain, localhost, $mydomain
home_mailbox = Maildir/
smtpd_sasl_type = dovecot
smtpd_sasl_path = private/auth
smtpd_sasl_auth_enable = yes
smtpd_recipient_restrictions = permit_mynetworks, permit_sasl_authenticated, reject_unauth_destination
mta_sts_policy = enforce
```

> 注：原文保留了 `mta_sts_policy = enforce` 一行。MTA-STS 并非 Postfix 原生支持的常见 main.cf 参数，落地时请确认你的 Postfix 版本是否认识该配置，不认识就去掉，否则 postfix check 可能报错。

几个关键项：

- myhostname：邮件服务器的主机名。
- mydestination：设置邮件可以送达的域名。
- home_mailbox：用户的邮箱目录，`Maildir/` 格式即每封邮件一个文件。
- smtpd_sasl_auth_enable：启用 SASL 认证，认证工作交给 Dovecot 完成。
- smtpd_recipient_restrictions：只允许本机网络和通过 SASL 认证的用户发信，其余未知目的地一律拒绝，避免被当成开放中继滥用。

重启并设置开机自启：

```bash
sudo systemctl restart postfix
sudo systemctl enable postfix
```

## 三、配置 Dovecot

Dovecot 负责邮件的接收（IMAP/POP3），同时给 Postfix 提供 SASL 认证服务。编辑主配置文件：

```bash
sudo vi /etc/dovecot/dovecot.conf
```

确保有以下配置：

```conf
disable_plaintext_auth = no
mail_privileged_group = mail
mail_location = maildir:~/Maildir
userdb {
  driver = passwd
}
passdb {
  args = %s
  driver = pam
}
service auth {
  unix_listener /var/spool/postfix/private/auth {
    group = postfix
    mode = 0660
    user = postfix
  }
}
```

`mail_location` 与 Postfix 的 `home_mailbox = Maildir/` 指向同一套邮箱；`service auth` 里的 unix_listener 就是 Postfix 配置里 `smtpd_sasl_path = private/auth` 对应的那个套接字，两边靠它接通认证。

启动 Dovecot：

```bash
sudo systemctl restart dovecot
sudo systemctl enable dovecot
```

## 四、测试邮件功能

发送测试邮件：

```bash
echo "Test email body" | mail -s "Test Email Subject" user@example.com
```

接收邮件：登录邮件客户端，或者用 mutt 直接在命令行里查看：

```bash
mutt
```

## 注意事项

- 用 firewalld 或 iptables 做访问控制，邮件服务器暴露在公网上，访问策略要收紧。
- 生产环境应配置 SSL/TLS 加密，保护邮件数据在传输中的安全。
- `disable_plaintext_auth = no` 允许明文认证，只在测试环境临时用，正式上线务必配合 TLS 并改回 yes。
- `smtpd_recipient_restrictions` 三条规则缺一不可，少了 `reject_unauth_destination`，服务器就可能被外部当跳板群发垃圾邮件。
