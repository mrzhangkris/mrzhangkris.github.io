本文在AlmaLinux9.2和CentOS7.6安装NFS，实现挂载网络文件

### 一、软件下载

服务端和客户端都使用yum命令安装nfs-utils

-   命令: yum install nfs-utils

### 二、规划

| 服务器 | 类型 | 目录 | IP地址 |
| --- | --- | --- | --- |
| AlmaLinux | 服务端 | /export/nfs | 192.168.0.237 |
| CentOS | 客户端 | /data | 192.168.0.35 |

### 三、部署

-   在服务端和客户端执行安装命令

```bash
yum install nfs-utils -y
```

-   服务端创建挂载目录并授权

```bash
mkdir -p /export/nfs
chmod 666 /export/nfs/
# 编辑/etc/exports文件，添加
/export/nfs 192.168.0.0/24(rw,no_root_squash,no_all_squash,sync)
# 配置生效
exportfs -r
```

-   服务端启动nfs服务

```bash
systemctl start rpcbind
systemctl restart nfs-server
```

-   客户端创建挂载目录，验证并挂载。

```bash
mkdir /data
showmount -e 192.168.0.237
mount -t nfs 192.168.0.237:/export/nfs /data/
```
