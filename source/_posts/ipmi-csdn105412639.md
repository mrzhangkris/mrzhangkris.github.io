服务器系统崩了、连 SSH 都进不去，传统远程管理就束手无策了。IPMI 就是为这种场景准备的：它工作在操作系统之下，只要机房还在供电，就能远程看硬件状态、开关机、装系统。这篇记录 IPMI 的基本概念和 ipmitool 的常用操作。

## IPMI 是什么

IPMI（Intelligent Platform Management Interface，智能平台管理接口）是一个通用的硬件管理接口标准，可以监视服务器的物理特征：温度、电压、风扇状态、电源供应、机箱入侵等。它最大的价值在于**独立于 CPU、BIOS 和 OS**——无论开机还是关机，只要接通电源就能管理服务器。

这套体系里最核心的部件是 BMC（Baseboard Management Controller，底板管理控制器），一块焊在主板上的嵌入式管理微控制器，相当于平台管理的"大脑"。它通过主板上的传感器采集数据并记录事件日志，主要功能包括：

1. 通过系统串行端口访问
2. 故障日志记录和 SNMP 警报发送
3. 访问系统事件日志（SEL）和传感器状况
4. 控制开机和关机
5. 独立于系统电源或工作状态运行
6. 文本控制台重定向，用于系统设置和操作系统控制台
7. 通过 LAN 访问 Red Hat Enterprise Linux 串行控制台

## 实际能做什么

通过 web 界面访问 IPMI（各厂商的带外管理口，如 Dell iDRAC、HP iLO），可以做这些事：

1. 服务器通电的情况下远程开机、关机、重启
2. 远程操作 BIOS，查看系统启动过程、登录系统
3. 远程安装系统
4. 修改 IPMI 的网络和 IP 地址
5. 设置 RAID

## 使用前提

1. 服务器主板上有 BMC。目前主流厂商的服务器基本都支持 IPMI，采购时确认一下即可。
2. 操作系统有对应的 ipmi 驱动。通过系统内部监控本机 IPMI 信息时，需要内核支持 OpenIPMI（Linux 内核自带）。

## 安装 ipmitool

```bash
[root@localhost ~]# yum install -y OpenIPMI ipmitool
```

## 常用操作

远程操作另一台机器的电源，`-H` 指带外管理口的 IP，`-U`/`-P` 是 IPMI 账号密码：

```bash
# 查看电源状态
ipmitool -H yourIP -U myuser -P mypassword power status

# 开机
ipmitool -H yourIP -U myuser -P mypassword power on

# 关闭电源
ipmitool -H yourIP -U myuser -P mypassword power off

# 断电重启
ipmitool -H yourIP -U myuser -P mypassword power reset

# 重启 BMC 自身（管理口卡死时用）
ipmitool -I lanplus -H yourIP -U myuser -P mypassword mc reset warm
```

更多操作查 `man ipmitool`。

## 注意事项

- IPMI 管理口一定要设独立强密码并限定在内网，它权限太大且历史上多次爆出高危漏洞，暴露公网是重大安全隐患。
- `power reset` 是硬重启，不通知操作系统，生产机器慎用。
- BMC 本身也可能卡死，`mc reset warm` 能远程救活管理口，不用跑机房。
- 本机监控自己的传感器不需要 `-H`，直接 `ipmitool sensor list` 即可。
