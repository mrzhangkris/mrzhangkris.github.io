内网里要给机器自动发 IP，或者希望某台设备每次都拿到同一个地址（按 MAC 绑定），就需要一台 DHCP 服务器。这篇以 CentOS 为例，记录从安装、配置到防火墙放行的完整流程，重点在 dhcpd.conf 里按 MAC 地址绑定 IP 的写法。

## 安装 DHCP 服务器

```bash
# 安装DHCP软件包
yum install dhcp
```

## 配置 DHCP 服务器

安装完成后，配置 DHCP 服务器来绑定 MAC 地址和 IP 地址。先备份原始配置文件再动手改：

```bash
# 备份原始的DHCP配置文件
cp /etc/dhcp/dhcpd.conf /etc/dhcp/dhcpd.conf.backup

# 编辑DHCP配置文件
vi /etc/dhcp/dhcpd.conf
```

配置文件内容分两部分：全局租期参数和子网配置。`host` 段就是按 MAC 绑定固定 IP 的关键：

```conf
# 全局配置参数
default-lease-time 600;
max-lease-time 7200;

# 子网配置
subnet 192.168.254.0 netmask 255.255.255.0 {
  range 192.168.254.150 192.168.254.200; # 动态IP地址范围
  option routers 192.168.254.2;         # 路由器地址
  option subnet-mask 255.255.255.0;   # 子网掩码
  # option domain-name-servers 8.8.8.8, 8.8.4.4; # DNS服务器
  # option domain-name "example.com";   # 域名

  # 根据MAC地址绑定IP地址
  host myclient {
    hardware ethernet 00:11:22:33:44:55; # 客户端的MAC地址
    fixed-address 192.168.254.150;           # 分配给该MAC的固定IP地址
  }
}
```

## 启动并启用 DHCP 服务

配置完成后，启动并设置 DHCP 服务开机自启：

```bash
# 启动DHCP服务
sudo systemctl start dhcpd

# 设置DHCP服务开机自启
sudo systemctl enable dhcpd

# 检查DHCP服务状态
sudo systemctl status dhcpd
```

## 配置防火墙

如果系统开着防火墙，要放行 DHCP 服务，否则客户端的请求根本到不了服务器：

```bash
# 允许DHCP服务通过防火墙
sudo firewall-cmd --permanent --add-service=dhcp

# 重新加载防火墙规则
sudo firewall-cmd --reload
```

## 测试

原文此处为客户端验证截图。验证方向：让客户端把网卡改成 DHCP 方式获取地址，确认拿到的 IP 落在 `range` 范围内，且 MAC 绑定的那台机器拿到的是 `fixed-address` 指定的固定地址。

## 注意事项

- 改 dhcpd.conf 前先备份，配置写错会导致 dhcpd 起不来，`systemctl status dhcpd` 的报错信息能定位到行。
- `default-lease-time` 是默认租期（秒），`max-lease-time` 是租期上限，本文配置分别是 600 秒和 7200 秒。
- `host` 段绑定的 MAC 要写成 `00:11:22:33:44:55` 这种冒号分隔格式，写错客户端拿不到绑定 IP。
- 绑定的固定地址必须在 subnet 声明的网段内，且避开 `range` 动态分配范围，否则可能地址冲突。
