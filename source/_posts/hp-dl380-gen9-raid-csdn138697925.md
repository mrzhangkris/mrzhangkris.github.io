新到的 HP DL380 Gen9 插好硬盘还不能直接装系统——装机程序只认逻辑盘，不认裸盘。裸盘必须先在 RAID 卡里组成阵列，才会以逻辑盘的形式交给操作系统。这篇记录用机器自带的 HPE Smart Storage Administrator（下文简称 SSA）完成这件事的完整流程，控制器以 Smart Array P440ar 为例。整个过程开机就能进，不需要额外的启动盘；本文为图形界面操作记录，未在命令行实跑，界面入口以实际固件版本为准。

## SSA 解决什么问题

Smart Array 系列控制器把"管理磁盘"这件事从操作系统挪到了固件层：建阵列、删阵列、设启动盘都在开机自检阶段完成，系统装好后看到的只是一块或几块现成的逻辑盘。这样做的好处是操作系统完全不用关心 RAID 细节——不管底下是几块盘、什么级别，装系统时它只看到一个普通磁盘。

SSA 就是控制器自带的图形管理界面，Gen9 机型把它内置在智能引导（Intelligent Provisioning）体系里，随开机 F10 进入，不需要额外的启动盘。对装机这件事来说，SSA 里要做的只有三件事：进界面、建阵列（选盘 + 选级别）、把新阵列设为启动盘。下面按这个顺序走。

## 第一步：进入 SSA

开机后在启动自检界面按 **F10**，进入智能引导菜单，从中选择 **HPE Smart Storage Administrator**。这一步不需要任何外置介质，固件自带。

> 注：不同固件版本的菜单层级略有差异。F10 之后如果先看到的是 Intelligent Provisioning 主界面，从 Perform Maintenance 里可以进 SSA；F9 进入的 System Utilities → System Configuration 下也有控制器入口，同样能到达。

进入 SSA 后，界面按"控制器 → 配置动作"两层组织：左边列出机器上的控制器（本例是 Smart Array P440ar）和挂在它下面的物理盘，选中控制器后右边给出可执行的动作。选控制器时值得顺带看一眼它的状态：物理盘列表里每块盘会标出状态（OK、Failed、未分配等），某块盘没出现在列表里，先检查背板线缆和硬盘位——控制器没识别到的盘做不了阵列；状态标 Failed 的盘也不能直接编进新阵列。

## 第二步：创建阵列

建阵列依次做四个选择：

1. 选择 **Smart Array P440ar** 控制器；
2. 选择 **Configure**，再选择 **Create Array**；
3. 勾选要加入 RAID 的物理硬盘；
4. 选择 RAID 级别，确认后完成创建。

选盘前先想清楚业务要的是容量还是安全——级别一旦选定，容量和冗余能力就定了，事后改级别要重建阵列、数据全丢。常见级别的取舍：

| RAID 级别 | 可用容量 | 容错 | 典型用途 |
|-----------|---------|------|---------|
| RAID 0 | 全部盘容量之和 | 无（坏一块全丢） | 缓存盘、临时数据 |
| RAID 1 | 单盘容量 | 坏 1 块 | 系统盘、小容量关键数据 |
| RAID 5 | (N-1) 盘容量 | 坏 1 块 | 通用业务盘 |
| RAID 10 | 一半容量 | 每组镜像坏 1 块 | 数据库等高 IO 场景 |

怎么选：装系统盘的惯例是单独一组小阵列（如两块盘做 RAID 1），数据盘另建，级别按业务定。RAID 5 省盘但有写惩罚——每次写都要算校验，随机写多的负载（数据库、虚拟化）不如直接上 RAID 10，用一半容量换性能和更快的重建。纯缓存、可随时重建的临时数据才考虑 RAID 0。

选盘环节还有两条固件层面的硬规则要记：

- **同一阵列内的硬盘必须是同一种介质**。SSD 和机械盘不能混编进一个阵列，容量、转速差异过大的盘混在一起也不合适；选盘时 SSA 会对不合规的组合直接拦截或告警。
- **新阵列会初始化所选硬盘**。勾选前确认盘上没有需要保留的数据，尤其中机房里接手的二手盘。

创建界面上还会有条带大小等附加选项，没有明确理由就保持默认——默认值对绝大多数场景是合理的，这些参数事后改不了，只能重建。

## 第三步：把新阵列设为启动盘

阵列建完还没有完——装机程序从哪块盘引导，取决于控制器的启动盘设置。回到该控制器的配置界面，选择 **Set Bootable Logical Drive/Volume**，选中刚创建的第一个逻辑盘，把它设为系统启动盘。

这一步最容易漏，而且 Gen9 默认 UEFI 模式下还有第二层：逻辑盘要真正参与引导，还得在引导顺序里排在前面。漏设启动盘，重启进入安装程序时可能找不到盘；机器上有旧阵列残留时，安装程序甚至会把系统装到另一块逻辑盘上。所以设完之后到 System Utilities 里确认一下引导顺序，让目标控制器排在首位。

设置完成后值得验证一下：重启进安装程序（或任意 Linux 救援环境），用 `lsblk` 应该能看到一块容量符合所选级别的盘——比如两块 300G 做 RAID 1，看到的逻辑盘容量就是 300G，系统装好后它通常就是 `/dev/sda`。

## 系统装好后的另一条路：ssacli

SSA 不只在固件里。系统装好后装 HPE 官方的 `ssacli` 命令行工具，可以在操作系统里查看甚至管理同一套阵列，批量脚本化时比进 BIOS 方便得多。常用命令形如：

```bash
ssacli ctrl all show status    # 控制器状态
ssacli ctrl all show config    # 控制器、阵列、逻辑盘全览
ssacli ctrl slot=0 ld all show detail   # 逻辑盘明细（级别、容量、状态）
```

> 注：`ssacli` 由 HPE Software Delivery Repository 提供（旧名 `hpssacli`/`hpacucli`），上述命令未实跑验证，来源为 HPE 官方文档，语法以安装版本的帮助输出为准。

日常巡检里最有用的是 `show config`：逻辑盘状态应为 OK，出现 Failed 或 Interim Recovery Mode 说明阵列降级，要及时处理。顺便说一句热备盘：在 SSA 里可以把某块未编入阵列的盘指定为 spare，阵列里坏盘后控制器自动用热备重建，不需要人工换盘——多盘位的机器建议留一块。

## 不对劲时：删掉重来

建错了级别、勾错了盘，回到同一控制器的 **Configure** 里用 **Delete Array** 删掉重建即可。删除动作当场生效且数据不可恢复——逻辑盘的元数据在控制器上，删阵列就是让控制器忘掉这组盘的编排，盘上原有内容随之不可访问。如果删掉的盘曾属于别的机器的阵列，重新建阵列时固件还会提示盘上有旧元数据，确认覆盖即可。二手盘、来历不明的盘，宁可先删后建，也不要在旧配置上叠加新阵列。

## 注意事项

- **先想清楚 RAID 级别再选盘**。级别决定可用容量和冗余能力，事后调整意味着重建阵列，数据全丢。
- **建完阵列必须设 Bootable Logical Drive**，并在 System Utilities 里确认 UEFI 引导顺序，否则装系统时可能找不到启动盘。
- **动手前确认盘上没有需要保留的数据**。Create Array 会初始化所选硬盘，已有数据的盘务必先备份；接手二手盘时尤其要先看清楚再勾选。
- **界面入口以实际固件版本为准**。本文按当时固件的界面记录，未实跑验证新版固件，但"建阵列 + 设启动盘"这两个动作在 SSA 里始终存在。

## 小结

回到开头的问题：裸盘不能直接装系统，因为它还没变成逻辑盘。在 DL380 Gen9 上这件事由固件层的 SSA 完成——F10 进界面，Create Array 选盘定级别，Set Bootable Logical Drive 指定启动盘，三步做完，安装程序面前就是一块可以直接分区的逻辑盘了。级别怎么选、启动盘别忘了设、同阵列不混介质，这三处是新手最容易踩的坑；装完用 `lsblk` 验一眼，系统起来后再用 `ssacli show config` 巡检，整个流程就闭环了。
