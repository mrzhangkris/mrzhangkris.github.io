排查"这个端口到底是谁在占、程序装在哪"的时候，用下面这个小脚本一步到位：传入端口号，直接拿到 PID 和进程的工作目录。

## 脚本

![配图](/images/csdn/figures/csdn134288829.png)

```bash
#!/bin/bash
##########################################################################################
####                 The input port returns the program process path                  ####
##########################################################################################

PID=$(netstat -nlp|grep :$1|awk '{print $7}'|awk -F"/" '{ print $1 }')
DIR=$(/usr/bin/pwdx $PID)
FILTERDIR=$(echo $DIR |awk -F ' ' '{print $2}')
echo -e "\033[31m The pid of port\033[0m \033[34m$1\033[0m \033[31mis\033[0m \033[33m$PID\033[0m \033[31mand the process path is\033[0m \033[33m $FILTERDIR \033[0m"
```

## 每一步在做什么

- `netstat -nlp | grep :$1`：找出监听传入端口的那个监听项；
- `awk '{print $7}'`：取第 7 列，内容形如"PID/程序名"；
- `awk -F"/" '{ print $1 }'`：按斜杠切开后取第一段，留下纯 PID；
- `pwdx $PID`：查询该进程的当前工作目录，输出形如"PID: 路径"；
- `awk -F ' ' '{print $2}'`：取 pwdx 输出的第二列，得到不带前缀的路径；
- 最后的 `echo -e` 用颜色把端口号和路径高亮出来。

用法：把脚本保存后以端口号作为第一个参数执行即可。

## 注意事项

- `grep :$1` 是子串匹配，查 `:80` 时可能连 `:8080` 的监听一起命中，必要时加词边界或精确匹配。
- `awk -F ' ' '{print $2}'` 只取 pwdx 输出的第一段路径，进程工作目录含空格时结果会不完整。
- netstat 的 `-p` 要看到进程信息需要足够权限，建议以 root 执行。
